# HyperText Markup Language

## HTML 5 
- Added new semantic components - new tags:
	- \<main>
		- main content (body of the document)
		- includes content that is unique to that document and excludes repeated data 
		- only one per document
	- \<section>
		- groups thematic content
		- many sections per document
	- \<article>
		- no clear distinction between sections and article - up to the developer; both sections and articles can be divided into multiple articles / sections
		- complete, self-contained body of text
	- \<footer>, \<header>
		- metadata
		- info common to several pages (like a navigation menu, for instance)
	- \<aside>
		- content related to the main content, but is not exactly part of the document
	- \<nav>
		- navigation buttons and stuff
	- \<svg>, \<audio>, \<video>
		- self explanatory
	- \<figure>, \<figurecaption> - alternative to image
